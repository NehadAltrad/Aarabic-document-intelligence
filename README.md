# Arabic Document Intelligence

An AI-powered system for Arabic document processing,
classification, and information extraction.

## Project Objectives
- Extract text from Arabic documents.
- Clean and preprocess Arabic text.
- Classify documents into predefined categories.
- Extract key information from documents.
- Evaluate model performance.

## Technologies
- Python
- Natural Language Processing (NLP)
- Machine Learning
- Streamlit
